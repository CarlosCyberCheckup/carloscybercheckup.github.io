Questions

Do you need access to my website or email?

No. The snapshot and report only use publicly visible information. For a Fix-It Session you stay in control and make the changes while we guide you.

Is this a penetration test?

No. This is a configuration checkup that covers the most common, most exploited gaps for small businesses. It does not attempt to break into anything.

My web developer handles this.

Great – send them the report. Email authentication (SPF/DMARC) usually falls between web and email providers, so it's the most commonly missed item.

Can this help with cyber insurance?

Many insurance questionnaires ask about email authentication and HTTPS. Our monthly report gives you documentation that these controls are in place.
